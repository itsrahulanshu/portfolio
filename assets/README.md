## How to Take Great Screenshots

### Tools
- **macOS:** Cmd + Shift + 4 (for custom area)
- **Windows:** Windows + Shift + S
- **Browser Extension:** Full Page Screen Capture (Chrome/Firefox)

### Tips for Better Screenshots
1. **Clean the interface** - Close unnecessary tabs/windows
2. **Use sample data** - Fill with realistic but generic data
3. **Highlight features** - Show the app in action
4. **Good resolution** - High-quality screenshots only
5. **Crop properly** - Remove extra whitespace
6. **Optimize size** - Use tools like TinyPNG to reduce file size
